📖 About the Universe

This is a 2-Billion character infinite universe generated mathematically using a single seed. The letters are not stored anywhere—they are calculated on demand.

Because the universe uses a uniform random distribution, short names appear frequently, while long names are mathematically rare.

  • Quick Scan: Scans 50 million characters.
  • Deep Scan: Scans 300 million characters.
  • Haystack: Scans the entire 2 billion universe.
